# 黎曼猜想研究之旅

> Understanding the Riemann Hypothesis: From Popular Science to Mathematical Research

## 项目目标

这个项目旨在系统地跟踪和理解黎曼猜想 (Riemann Hypothesis) 的研究进展，从科普层面逐步深入到严肃的数学证明研究。

## 学习路径

### 第一阶段：基础科普 (Popular Science)
- 黎曼猜想的历史背景
- ζ函数 (Riemann zeta function) 的基本概念
- 素数分布与黎曼猜想的关系
- 哥德巴赫猜想、孪生素数猜想等相关问题

### 第二阶段：数学基础 (Mathematical Foundations)
- 复分析基础
- 解析数论入门
- L-函数与自守形式
- 筛法 (Sieve Methods)

### 第三阶段：前沿研究 (Research Frontiers)
- 随机矩阵理论与统计物理的联系
- 阿蒂亚的证明尝试及其争议
- 近年的重要进展与候选证明
- 计算验证的最新成果
